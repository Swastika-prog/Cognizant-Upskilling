# Cognizant Upskilling

Weekly hands-on exercises from the Cognizant full-stack upskilling cohort, covering Angular, Spring / Spring Boot, Spring Cloud microservices, and React.

## Week 1 — Angular Fundamentals
`week1/` — An Angular CLI project (*Student Course Portal*) scaffolding the app shell: a `Header` component, routing setup, and placeholder pages for `Home`, `Course List`, and `Student Profile`.

## Week 2 — Spring Core (IoC & Dependency Injection)
`week2/Exercise4/` — A plain Maven + Spring Context project demonstrating the Spring IoC container: a `@Configuration` class declaring a `@Bean`, loaded via `AnnotationConfigApplicationContext` and resolved through dependency injection.

## Week 3 — Spring Boot REST APIs
`week3/spring-rest-handson/` — A Spring Boot app with REST controllers: a basic `/hello` endpoint, a `/countries` endpoint (list + lookup by code), a JWT-based `/authenticate` login endpoint, and a demo of classic XML-based Spring bean configuration.

## Week 4 — Spring Cloud Microservices
`week4/microservices-handson/` — A multi-module microservices setup: a `eureka-server` for service discovery, an `api-gateway` for routing, and two domain services — `account-service` and `loan-service` — each exposing simple REST endpoints, registered with Eureka.

## Week 5 — Angular (continued)
`week5/student-course-portal/` — Continuation of the Angular *Student Course Portal* from Week 1, carrying forward the same component/routing structure for further iteration.

## Week 6 — Angular (continued)
`week6/student-course-portal/` — Further continuation of the *Student Course Portal*, building on Weeks 1 and 5.

## Week 7 — React
`week 7/cohorttracker/` — A React app (*Cohort Tracker* — this repository's namesake) that renders a list of training cohorts (code, technology, trainer, coach, status) using props, `.map()` list rendering, conditional styling, and CSS Modules.
